# ฝากงาน — M3 School Web App

เว็บแอปภาษาไทยสำหรับฝากงานในโรงเรียน ทำด้วย HTML/CSS/JS ไฟล์เดียว ธีม Material Design 3

## ฟีเจอร์

- เข้าสู่ระบบ (username / password) และสมัครบัญชี
- ตั้งชื่อ รูปโปรไฟล์ พร้อมหน้าครอบรูป และแบนเนอร์โปรไฟล์
- เลือกระดับชั้น M.1–M.6 (ระดับละ 13 ห้อง)
- ติดตามห้องด้วยการปัดการ์ดซ้าย/ขวา
- ฝากงาน / นัดสอบ / เฉลยงาน พร้อมรูป ไฟล์ และลิ้งค์
- ถูกใจ (เซฟ) งาน, คอมเม้นต์ (แก้/ลบได้), ลบงาน
- แชทส่วนตัวและกลุ่ม พร้อมส่งรูป/ไฟล์, ตอบกลับข้อความ, ใส่ความรู้สึก (❤️ 👍 😂 😮 😢), ซ่อนแชทเฉพาะบัญชีตัวเอง
- รวมแชทส่วนตัวที่ซ้ำกับคนเดียวกันให้เป็นห้องเดียว
- กรองตามชนิดงานและวิชาในหน้าหลัก / ฝากงาน / ประวัติ
- เลือกสี 5 โทน และโหมดสว่าง/มืด
- ใช้ localStorage เก็บข้อมูลในเบราว์เซอร์ (ไม่มีเซิร์ฟเวอร์)

## ใช้งาน

เปิด `index.html` ในเบราว์เซอร์ หรือเข้าผ่าน GitHub Pages ของ repo นี้

## ระบบบัญชีและข้อมูล

- ใช้ **Firebase Authentication** (Email/Password) — อีเมลของบัญชีคือ `<username>@fakjob.local`
- ข้อมูลซิงก์ผ่าน **Cloud Firestore** แบบ realtime (งาน / แชท / คอมเม้นต์ / โปรไฟล์)
- บัญชีที่ย้ายมาจากระบบเก่าต้อง **ตั้งรหัสผ่านใหม่ครั้งแรกที่ล็อกอิน** (รหัสชั่วคราว `Fakjob@1234`)
- กฎความปลอดภัยอยู่ใน `firestore.rules` — ต้อง publish ใน Firebase Console
- ข้อมูลสำรองในเครื่องใช้ localStorage เพื่อให้เปิดแอปได้ทันที
