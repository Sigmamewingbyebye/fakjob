# ฝากงาน — M3 School Web App

เว็บแอปภาษาไทยสำหรับฝากงานในโรงเรียน ทำด้วย HTML/CSS/JS ไฟล์เดียว ธีม Material Design 3

## ฟีเจอร์

- เข้าสู่ระบบ (username / password) และสมัครบัญชี
- ตั้งชื่อ รูปโปรไฟล์ พร้อมหน้าครอบรูป และแบนเนอร์โปรไฟล์
- เลือกระดับชั้น M.1–M.6 (ระดับละ 13 ห้อง)
- ติดตามห้องด้วยการปัดการ์ดซ้าย/ขวา
- ฝากงาน / นัดสอบ / เฉลยงาน พร้อมรูป ไฟล์ และลิ้งค์
- ถูกใจ (เซฟ) งาน, คอมเม้นต์, ลบงาน
- กรองตามชนิดงานและวิชาในหน้าหลัก / ฝากงาน / ประวัติ
- เลือกสี 5 โทน และโหมดสว่าง/มืด
- ใช้ localStorage เก็บข้อมูลในเบราว์เซอร์ (ไม่มีเซิร์ฟเวอร์)

## ใช้งาน

เปิด `index.html` ในเบราว์เซอร์ หรือเข้าผ่าน GitHub Pages ของ repo นี้

> ข้อมูลทั้งหมดเก็บในเบราว์เซอร์ของผู้ใช้แต่ละคน ไม่ได้ซิงก์ข้ามอุปกรณ์
